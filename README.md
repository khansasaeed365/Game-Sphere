Game Sphere

Game Sphere is a C++ console-based project that combines four exciting games into one application.

Games Included

Hangman

A word-guessing game where players try to reveal a hidden word by guessing letters within a limited number of attempts.

Escape Room

A puzzle and adventure game where players solve clues and challenges to escape successfully.

Chess

A two-player strategy board game based on standard chess rules.

Tic Tac Toe
